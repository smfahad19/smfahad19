## 🌟 **AWS EC2 Architecture Patterns**

<div align="center">

### **High Availability Architecture**
```
┌─────────────────────────────────────────────────────┐
│                    Route 53 DNS                      │
└──────────────────────────┬──────────────────────────┘
                           │
                ┌──────────▼──────────┐
                │  Application Load   │
                │     Balancer        │
                └──────────┬──────────┘
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
┌───────▼──────┐  ┌───────▼──────┐  ┌───────▼──────┐
│   EC2 Instance│  │   EC2 Instance│  │   EC2 Instance│
│    AZ: us-east│  │    AZ: us-east│  │    AZ: us-west│
│   -1a         │  │   -1b         │  │   -1a         │
└───────┬──────┘  └───────┬──────┘  └───────┬──────┘
        │                  │                  │
        └──────────────────┼──────────────────┘
                           │
                ┌──────────▼──────────┐
                │   Auto Scaling      │
                │      Group          │
                └─────────────────────┘
```

### **Microservices on EC2**
```
┌─────────────────────────────────────────────────────┐
│                 NGINX Reverse Proxy                  │
│           (Routing & Load Balancing)                 │
└──┬────────────────┬────────────────┬────────────────┘
   │                │                │
┌──▼────┐     ┌────▼──┐      ┌─────▼──┐
│ Auth  │     │ Product│      │ Order  │
│ Service│     │ Service│      │ Service│
│(EC2)   │     │ (EC2)  │      │ (EC2)  │
└──┬────┘     └────┬──┘      └─────┬──┘
   │                │                │
┌──▼────┐     ┌────▼──┐      ┌─────▼──┐
│ Redis │     │ MongoDB│      │  MySQL │
│ Cache │     │ Cluster│      │   RDS  │
└───────┘     └────────┘      └────────┘
```

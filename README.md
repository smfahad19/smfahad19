## About Me

I'm Fahad, a Full Stack Developer in Lahore — 6th semester BS Software Engineering at The Superior University.

**Syed Watch Company (SWC)** is my proudest build — a live store for my own family's 50-year-old watch and leather business. Real customers, real checkout, and real production fires I had to put out myself: CORS across environments, Prisma binary target mismatches, a full migration off Vercel serverless onto a self-managed DigitalOcean droplet.

I've also built backend systems for a production HR platform at Ezitech Solutions, and an e-commerce app at Itsolera.

- 🔭 Currently building: **HireUp Pakistan** — solo, on Next.js + Framer Motion
- 🌱 Learning: system design, advanced Next.js patterns
- 💼 Open to: junior/mid Full Stack roles & freelance work
- 📍 Lahore, Pakistan

## Projects

### 🕐 Syed Watch Company (SWC)
> Live e-commerce platform for a real family business, running in production

Product catalog, cart, secure checkout, Google OAuth login, admin dashboard, Cloudinary-managed image pipeline. Started on Vercel serverless, later migrated the backend to a self-managed DigitalOcean droplet (Nginx) after hitting production scaling issues.

**Stack:** React · Redux · Node.js · Prisma · PostgreSQL · Supabase · Cloudinary · Google OAuth
[🔗 Live Demo](https://swc-syed-watch-company.vercel.app) · [📂 GitHub](#)
